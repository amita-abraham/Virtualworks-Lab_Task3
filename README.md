# Virtualworks – Lab – Task 3
## Pharmacy Sales & Drug Analysis Dashboard (Germany, 2019–2020)

### 📌 Project Overview
This project focuses on analyzing pharmacy sales and drug data in Germany for the years **2019 and 2020**. An interactive dashboard was created to explore sales performance, identify trends, and present key insights through visualizations.

The dashboard uses Microsoft Excel features to organize, summarize, and visualize pharmacy sales data, supporting easier comparison and interpretation of sales patterns.

### 🎯 Objectives
- Analyze pharmacy sales performance across 2019 and 2020.
- Identify sales trends and patterns.
- Compare sales performance across different periods and drug categories, where available.
- Present key information through an interactive dashboard.

### 🛠️ Tools & Features Used
- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Slicers for interactive filtering
- Data formatting and visualization
- Dashboard design and layout

### 📊 Key Features
- Interactive dashboard for pharmacy sales analysis.
- Dynamic filtering using slicers.
- Summarized data using Pivot Tables.
- Visual representation of sales trends using Pivot Charts.
- Comparison of pharmacy sales data for 2019 and 2020.

### 📅 Data Coverage
- **Country:** Germany
- **Years:** 2019–2020
- **Domain:** Pharmacy Sales & Pharmaceutical Drug Analysis
